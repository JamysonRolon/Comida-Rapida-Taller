# Seguridad

No publique contraseñas, datos personales ni detalles de una vulnerabilidad en una incidencia pública. Use la sección **Security** del repositorio para informar una vulnerabilidad de forma privada cuando esa opción esté disponible.

Las credenciales de PostgreSQL y de las cuentas ficticias se configuran con variables de entorno. Los scripts locales las guardan únicamente en `.work`, carpeta excluida de Git.
